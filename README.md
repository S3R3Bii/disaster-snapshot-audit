# Check disaster funding snapshots before comparing counties

This is a planned data-availability audit and local snapshot-comparison guard for two fixed OpenFEMA disaster cohorts. No project-record results have been computed.

The original question asks when county spending comparisons become stable. Earlier discovery did not establish historical county-value snapshots. The original protocol explicitly permits a data-availability study when history is unavailable. This execution will inspect what current funded-project records and actual captured metadata can support, while leaving the historical stability horizon unknown.

FEMA defines county as the applicant location, which can differ from the location of damaged work. Its current funded-project dataset excludes pre-obligation projects, incorporates migration-related population changes and is not intended for official federal reporting.

Read [the fixed protocol](PROTOCOL.md), [source definitions](data/source_contract.json), [source history](SOURCE_HISTORY.md) and [data terms](DATA_RIGHTS.md). Source capture and independent checks must pass before any result or release claim.

This product uses the Federal Emergency Management Agency’s OpenFEMA API, but is not endorsed by FEMA. The Federal Government or FEMA cannot vouch for the data or analyses derived from these data after the data have been retrieved from the Agency's website(s).
